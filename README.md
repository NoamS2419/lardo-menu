# לארדו תפריט

אתר פנימי ללימוד המוצרים וסידור המשמרות לעובדי הסניף. אתר סטטי (HTML/CSS/JS בלי בנייה), יושב על GitHub Pages.

למתכנתים: הסבר מלא על המבנה, התפקידים, הנתונים ואיך משנים דברים נמצא ב-[ARCHITECTURE.md](ARCHITECTURE.md).

- `data/products.json` — כל המוצרים. נוצר ע"י `tools/build.py` משליפת וולט + הערות הצוות; לא לערוך ידנית. רענון ומבנה: [tools/README.md](tools/README.md).
- `data/images/` — תמונות המוצרים (מורדות ע"י ה־Action "Refresh from Wolt").
- `js/main.js` — נקודת הכניסה: טעינת הנתונים, ניתוב בין דפים, תמונה חלופית.
- `js/catalog.js` — קטלוג, קטגוריות, דף מוצר, חיפוש, דפי מידע.
- `js/learn.js` — כרטיסיות ומשחקים.
- `js/progress.js` — התקדמות אישית (נשמרת רק בטלפון).
- `js/shifts.js` — משמרות לעובדים: כניסה והרשמה, הגשת זמינות, חופש, המשמרות שלי, כרטיס בדף הבית.
- `js/manage.js` — ניהול סידור (אור): הצוות ואישורים, הגדרות, בניית הסידור ופרסום, סניפים (למנהל הראשי). `js/share.js` — תמונה לוואטסאפ.
- `js/menu.js` — שינויים בתפריט (אוסף `menu` ב-Firestore) שמונחים מעל `data/products.json` בכל טעינה, ולכן נשארים גם אחרי עדכון מוולט. `js/menu-admin.js` — המסכים שבהם מי שמנהל סידור (או המנהל הראשי) מסתיר מוצר, משנה שם, תיאור, מחיר וטיפ, מוסיף מוצר, ועורך שאלות של לקוחות וטיפים למכירה.
- `js/account.js` — חשבונות (שם משתמש + סיסמה, כתובת פנימית `@staff.lardo.invalid`); `js/fs.js` — Firebase ב־REST, בלי SDK; `js/week.js` — תאריכים לפי שעון ישראל.
- `js/team.js`, `js/cloud.js` — טבלת הצוות, רק לעובדים מאושרים ובשם מהסידור. הכללים ב־`firestore.rules` (נבדקים ב־`tests/`).
- `js/core.js` — מצב משותף ועזרי עיצוב; `js/fx.js` — אנימציות חגיגה (מושבתות ב־reduced motion).

בלי Analytics ובלי עוגיות. חסום לאינדוקס בגוגל (`noindex`).

הרצה מקומית: `python3 -m http.server` ולפתוח את `http://localhost:8000`.

## אבטחה: חשוב

- **לא לפרסם שום אתר GitHub Pages נוסף בחשבון `NoamS2419`.** כל האתרים בחשבון חולקים את אותו origin (`noams2419.github.io`), ואתר אחר יוכל לקרוא את פרטי הכניסה של אור ושל העובדים. אם צריך עוד אתר: חשבון אחר, או דומיין משלו לאתר הזה.
- אימות דו־שלבי ב־GitHub ובחשבון Google של Firebase.
- המנהל הראשי מוגדר ב־`firestore.rules` לפי uid (`__ADMIN_UID__`). הכפתור "העתקת החוקים" בחשבון של `noam` (לשונית משמרות → החשבון שלי) ממלא אותו לפני ההדבקה במסוף.

## בדיקות

```
cd tests && npm i
npm run rules   # בדיקות החוקים באמולטור (צריך Java)
npm run dev     # אתר מקומי על האמולטורים: http://localhost:8123/?emu
```
חשבונות הבדיקה (סיסמה `password1`): noam (מנהל ראשי), or (ניהול סידור), roni, lia, dan (ממתין לאישור).

## שמירת נתונים

זמינות, סידורים, טיוטות ובקשות חופש נמחקים 3 חודשים אחרי השבוע שלהם, ועובד שהושבת נמחק 3 חודשים אחרי ההשבתה. אין TTL בפרויקט: המכשיר של מי שמנהל את הסידור מוחק אותם כשנכנסים ל"ניהול סידור". תוצאות האתגר היומי נמחקות אחרי 60 יום באותה דרך מעמוד הצוות. משתמש ה־Auth עצמו (רק שם משתמש) נשאר עד שמוחקים אותו במסוף.
